# Keep making it better (weekly, about 10 minutes)

1. **Read 10 bot conversations** in Instagram or the Zernio inbox. Pick a mix:
   ones that booked or bought, ones that went quiet, and any HANDOFFs.
2. **Bring them to Claude** (this skill: "improve my DM setter") with the
   current `setter.md`. Paste or screenshot the threads.
3. For each thread, decide: would you have said that? Where did it lose them?
4. **Fix the file** the same way as testing: corrected examples first, then
   facts, then flow. Keep it short. Delete rules that never matter.
5. **Re-test** the changed spots with role-play, paste the new file into
   GitHub (connect.md part C), and you're done.

## Numbers worth watching
- Replies to the bot's first message (are openers working?)
- Links sent → booked or bought (is the qualifying working?)
- HANDOFFs per week (too many means the file is missing answers)

## When to change something bigger
- Lots of "how much" and then silence: decide whether to show the price or
  explain why it depends, and test both for a week each.
- People ask the same unanswered question: add it to Common questions.
- Wrong people booking: tighten "Who this is for" and the qualifying questions.
